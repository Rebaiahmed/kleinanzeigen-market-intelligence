# Reproducible research methodology

No rights-cleared real dataset was identified for this initial release; no market findings are reported. To conduct a real study, obtain a permitted dataset, record permissions and dates, define the population and sampling method, check for private data, document exclusions and currency, and preserve a versioned input under appropriate access controls. Report sample size, missingness, selection bias and observation period alongside price medians and percentiles. Asking prices are not observed transaction prices.

For evaluation, use independently human-reviewed reference labels with a documented definition of product equivalence, conditions and categories; hold ambiguous pairs out separately. Report confidence intervals and slices where sample sizes support them. Price reference zero cannot be used in MAPE. Compare reference labels and outputs only on disjoint evaluation data; never treat synthetic checks as measured model performance.

For future model comparisons record immutable model and prompt versions, dataset version, evaluation date, error rates, latency, token counts and estimated cost, while never sending personal data without authorization. No network benchmark is supplied or scheduled in this release.
